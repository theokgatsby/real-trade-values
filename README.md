# Real Trade Values

A RuneLite plugin that displays the actual total value in trade windows when values exceed the 2.1B integer limit (replacing "Lots!"), and calculates real custom values for items worth over max cash (such as 3rd Age items).

## Features

- **Accurate Trade Values**: Replaces "Lots!" text with exact, formatted trade values across both items being sent and items received.
- **Both Trade Windows Supported**: Works on the main trade screen and the trade confirmation screen.
- **Price Checker Support**: Applies the same custom prices to individual items, stacks, and the total in the price checker, including values above max cash.
- **Over Max Cash Item Valuation**: Configurable value overrides in billions of GP for items traded above max cash:
  - 3rd Age pickaxe
  - 3rd Age axe
  - 3rd Age felling axe
  - 3rd Age druidic robe top
  - 3rd Age druidic robe bottoms
