# Real Trade Values

A RuneLite plugin that displays the actual total value in trade windows when values exceed the 2.1B (max integer) limit (replacing "Lots!" and removing the "coins" text), and calculates real custom values for items worth over max cash (such as 3rd Age items).

## Features

- **Accurate Trade Values**: Replaces "Lots!" and the default "(X coins)" text with exact, formatted trade values across both items being sent and items received.
- **Both Trade Windows Supported**: Works on the main trade screen and the trade confirmation screen.
- **Over Max Cash Item Valuation**: Configurable value overrides in billions of GP for items traded above max cash:
  - 3rd Age pickaxe
  - 3rd Age axe
  - 3rd Age felling axe
  - 3rd Age druidic robe top
  - 3rd Age druidic robe bottoms
